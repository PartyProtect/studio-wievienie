# Documentation

`AGENTS.md` at the repository root is the primary guide for current creative and working decisions.

The files in this folder are retained as research and project history. Some describe earlier visual directions, technical ideas, SEO plans or page structures that were never implemented or have since changed.

Use them for background and useful facts, not as automatic instructions. When they conflict with the current site, current requirements or `AGENTS.md`, follow the current reality.
