# Documentation

`AGENTS.md` at the repository root is the primary guide for current creative and working decisions.

## Current documents

- `project-reference.md` describes the current parent-site / project-world architecture and technical boundaries without assigning a visual style to future projects.
- `visual-design-system.md` describes what is genuinely shared across the site and, equally importantly, what should remain project-specific.
- `tested-workflows.md` contains useful testing and optimization procedures.
- `seo-strategy.md` and `google-search-central-reference.md` contain SEO research that should be checked against the current implementation before being applied.

## History is context

This repository has gone through several design and architecture explorations. Git history preserves those versions, including an earlier Quiet Editorial visual system and a March 2026 route/content plan.

Historical documents can contain valuable techniques, research and abandoned ideas, but they are not automatic instructions. Do not resurrect an old palette, font pairing, route hierarchy, animation pattern or page template simply because it was once documented.

When old material conflicts with direct current requirements, real source material, the current architecture or `AGENTS.md`, follow the current reality.

A useful technique from an old direction may still be reused deliberately. Reuse the idea because it solves the present problem, not because history named it a standard.
